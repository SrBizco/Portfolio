# Máximo Gianetti Portfolio

Static portfolio for GitHub Pages.

## Local Preview

Open `index.html` in a browser.

## GitHub Pages

1. Create a repository named `maxigianetti.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
3. In GitHub, go to `Settings > Pages`.
4. Set source to `Deploy from a branch`, branch `main`, folder `/root`.
5. Visit `https://maxigianetti.github.io`.
